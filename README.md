# Academy Foundation — A Pointers Course

**Enough Google Colab and Python to open a POC Learning Lab notebook, run it, and understand what it did. No more, no less.**

This repository is the foundation course of the **GAI Observe Academy**, the learning arm of GAI Observe LLC. It exists for one practical reason: members of the **Agentic AI Learning Community — GAI Observe Academy** kept meeting the same first obstacle. The Lab notebooks are where our learning happens, but a notebook only teaches you something if you can open it, run it, and follow what the code is doing. This course removes that obstacle.

## Who this is for

- Community members who are new to code, or returning to it after a long break, and want to follow the **POC Learning Lab** (our public lab of small, worked proof-of-concept notebooks).
- Practitioners who can read about AI all day but have never run a notebook cell themselves.
- Anyone the Academy orientation package sends here. This repo is referenced from that orientation package as the starting point before the Lab.

You do not need to install anything. Everything here runs in a browser, through Google Colab, with a free Google account.

## What this is — and what it is not

**This is a pointers course.** It tells you, in plain language and in the right order:

- what you need to learn,
- why it matters for our Lab specifically, and
- which well-regarded external course or resource teaches it properly — with a link.

**This is not a full foundational course, and it does not pretend to be one.**

- It **teaches no certificates** and awards nothing. Where a certificate exists, it belongs to the provider whose course you actually took.
- It **does not replace** the real foundational courses — not a university programme, not Google's courses, not Coursera's. It *points to them*, deliberately. The deep teaching is theirs; the sequencing, the Lab connection, and the honesty about how much you actually need are ours.
- It is **scoped to the Lab**. The Python here goes exactly as deep as the POC notebooks go, and stops there. If a notebook never uses a concept, this course does not make you learn it first.

## How to use it

Work through [`curriculum.md`](curriculum.md) from Module 0 to Module 4, in order. Each module has three parts:

1. **What to learn** — the small set of ideas, in our own words.
2. **Why it matters for our Lab** — the specific place those ideas show up in the POC notebooks.
3. **Pointers** — the external courses and references that teach it, named with their provider.

Most members need a few sittings, not a semester. When you finish Module 4, open your first Lab notebook and run it end to end. That run is the real graduation.

## The one habit this course insists on

**Read → run → verify.** Read code before you run it. Run it. Then check that what it produced is what you expected — and if it isn't, that gap is the learning. This applies to code you write, code an AI assistant writes for you, and code in our own Lab notebooks, including ours. Our notebooks label their runs honestly — INTERIM for demonstrations, ILLUSTRATIVE for figures that show a pattern rather than a measurement — and Module 4 shows you how to read those labels.
